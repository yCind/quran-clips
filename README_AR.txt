مشروع حسنة - نسخة التطوير 1.1
================================

المتطلبات:
- Android Studio حديث يدعم Android Gradle Plugin 8.5.2.
- JDK 17.
- Android SDK Platform 34.
- اتصال بالإنترنت لتنزيل اعتماديات Gradle ومكتبات الخطوط والقراءات.

طريقة البناء:
1) فك ضغط الأرشيف.
2) افتح مجلد المشروع في Android Studio.
3) انتظر Gradle Sync.
4) اختر Build > Build Bundle(s) / APK(s) > Build APK(s).

ملاحظات:
- التشغيل في الخلفية الأصلي يستخدم AndroidX Media3.
- القارئان ياسر الدوسري وإسلام صبحي يجري اكتشاف مصاحفهما من MP3Quran API وقت التشغيل؛ يلزم اتصال إنترنت.
- عبد الرحمن مسعد يظهر كرابط لقناته الرسمية على YouTube لعدم توفر ملف MP3 مباشر موثق له ضمن مصدر MP3Quran المستخدم.
- القراء الجدد في قسم الاستماع يشغلون السورة كاملة؛ قائمة إنشاء الفيديو الحالية تبقى معتمدة على القراء المتاحين آيةً بآية حتى لا يتم إنشاء مقاطع غير متزامنة.
- لا يتضمن هذا الأرشيف APK جاهزاً؛ بيئة التحرير لم تحتو Android SDK أو Gradle، لذلك يلزم البناء من Android Studio.
